# Technology Stack

- **Frontend UI:** Next.js (React), Tailwind CSS, Recharts for Analytics.
- **Backend API:** FastAPI (Python) for asynchronous multi-model GPU orchestration.
- **LLM & ASR Engine:** Groq API (LLaMA-3.3-70B-versatile, Whisper-large-v3-turbo).
- **TTS Engines:** Kokoro (82M), Qwen3-TTS (0.6B), IndicF5.
- **Knowledge Base:** Sentence-Transformers (`all-MiniLM-L6-v2`) on CPU.
- **Database & Auth:** Supabase (PostgreSQL, Storage, Authentication).
