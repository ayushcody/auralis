# Project Objectives

- **Unified Studio Experience:** Provide Voice Cloning, Knowledge Hub (RAG), and Agent configuration in a single beautiful web interface.
- **Smart GPU Orchestration:** Implement an LRU (Least Recently Used) cache manager to seamlessly hot-swap TTS models (Kokoro, Qwen, IndicF5) without OOM crashes.
- **Ultra-Low Latency Conversation:** Leverage Groq's LPU inference for instant LLM/ASR processing to achieve near-human conversation speeds.
- **Automated Adversarial Evaluation:** Build an LLM-as-a-Judge evaluation lab to automatically grade agent resilience against prompt injections and hallucinations.
