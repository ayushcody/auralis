# What is Auralis?

- An advanced, end-to-end Voice Intelligence Platform.
- Powered by a **Multi-Model Architecture**: Qwen3-TTS (Cloning), Kokoro (Fast Base TTS), IndicF5 (Regional).
- **Conversational Agents:** Seamlessly connects real-time ASR, LLM logic (LLaMA-3.3-70B via Groq), and TTS routing.
- **Knowledge Grounding:** Built-in RAG (Retrieval-Augmented Generation) so voices speak accurately based on uploaded PDFs.
- **Zero-Shot Cloning:** Replicates a human voice using just 3–10 seconds of reference audio.
